An entry for the [Seventeen Syllables of Debugging](https://make.fun/bounty/u-irvan-motion-seventeen-syllables-of-debugging-d194b605) competition on make.fun.

`main.ts` is a small Node program (Node 22, no dependencies, no network) that writes one haiku about debugging to `/output/entry.txt` (overridable with the `OUTPUT_DIR` environment variable for local testing). The output is deterministic: every run writes byte-identical output.

## The haiku

> Breakpoint holds its breath
> The cursor blinks past midnight
> It was always me

Three lines in the 5-7-5 syllable shape. A breakpoint waits, a cursor blinks past midnight — and the last line turns the whole scene: after hours of staring at the machine, the bug was the person staring all along.
